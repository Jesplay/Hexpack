# Find Anything

## The 4 shortcuts that do 90% of it
| Keys | What it does | Try typing |
|---|---|---|
| **Ctrl + O** | **Quick switcher**: jump to any note by name *or alias*. Book pages also answer to the **items** they describe. | `mote nexus`, `impetus`, `staff`, `thoth`, `explosion` |
| **Ctrl + Shift + F** | **Full-text search** across everything | `"flay"`, `tag:#topic/movement`, `path:"02 Patterns/Hexal"` |
| **Ctrl + P** | **Command palette** | `graph`, `reload app` |
| **Alt + ← / →** | Back / forward, like a browser | |

> [!tip] Search tricks (Ctrl + Shift + F)
> - `tag:#hexcasting/spell explosion`: spells mentioning explosions
> - `tag:#topic/movement tag:#mod/hexal`: Hexal movement patterns
> - `[kind:Great Spell]`: by property
> - `"Charged Amethyst"`: exact phrase, e.g. to find expensive things
> - `tag:#hexcasting/needs-enlightenment`: everything locked behind enlightenment
> - `tag:#hexcasting/not-in-book`: patterns the book never mentions
> - `tag:#hexcasting/disabled-in-pack`: patterns this server blocks

## In every pattern note
Drawing · **Unlock** status (free / needs enlightenment / per-world / disabled) · stack effect · cost · description · example · **Topics** · related patterns · **Sources** (book page, official online docs, Modrinth page, where the strokes came from).

## In every book page
The book text, every pattern on it with its drawing, **readable crafting recipes** (grid + ingredients, read from the mod files), and links to the official online docs.

Hover any `[[link]]` to preview it without leaving the page.
