# What is a Hex?

> **Category:** [[Hex Casting (Category)|Hex Casting]]  
> **Source mod:** [[Hex Casting]]

Conceptually, a **Hex** is exactly as described in [[Hex Casting 101]]: a sequence of actions, usually done with the goal of performing some kind of effect in the world by means of one or more spells.

This idea of a **Hex** is fine for on-the-fly casting, but if I wish to record my work for posterity (or simply for my own reuse) I may need something a little more concrete.

Typically, this takes the form of a list of pattern [[Iotas|iotas]], as created by the techniques described in [[Escaping Patterns]]. With my **Hex** placed onto the [[The Stack|stack]] this way, I can cast it using meta-evaluation patterns like [[Hermes' Gambit]], or infuse it into a [[Casting Items|Casting Item]] item for easy reuse.

Note that this list is no different from any other list iota - I can manipulate it, save it into [[Thought-Knot|permanent]] [[Focus|storage]], or even incorporate it into another **Hex**.

Note also that this list need not be composed exclusively of pattern iotas. Inserting iotas of other types into my **Hexes** won't normally end well, but [[Escaping Patterns|certain techniques]] allow me to do it safely. Furthermore, some [[Iris' Gambit|special iotas]] can be directly evaluated just like a pattern.

With this in mind, *any* list of iotas can in theory be a **Hex** - the only requirement is that I can successfully cast it.
