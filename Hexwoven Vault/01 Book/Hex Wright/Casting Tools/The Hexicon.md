# The Hexicon

> **Category:** Hex Wright › [[Casting Tools (Category)|Casting Tools]]  
> **Source mod:** [[Hexwright]]

### Hexicon

*Item:* **Hexicon**

A magical book capable of holding 72 hexes. There are 8 chapters, each with 9 pages, and each page can hold a hex. Change the cover by casting [[Caster's Glamour]] with it in hand.

### Reading It

Hold your Hexicon Selector key for a quick select. Press a number to select or use the mouse wheel to move chapters.

### Editing It

Double-tap the same key to open the full editor instead, where you can flip through every chapter and write or rewrite any of the seventy-two pages.
Use [[Scribe's Gambit]] to write to a selected page, or [[Engraver's Gambit]] through a Scribe Core [[Staves|staff]].
Use [[Scribe's Reflection]] to read the hex on the current page.

### Quick Menu Shortcuts

Pressing a number will select that page.

Double tapping a number will change the chapter to that number.
