# The Resonant Anchor

> **Category:** Hex Wright › [[Casting Tools (Category)|Casting Tools]]  
> **Source mod:** [[Hexwright]]

### Resonant Anchor

*Item:* **Resonant Anchor**

A spatial anchor forged with the same resonant frequency as Amethyst.
Greater teleporting to it's position prevents any accidental loss of personal belongings and deals with the rematerialisation of those teleporting.

### A Free Landing

Aim a [[Greater Teleport]] at a tuned anchor and the cast is free and drops nothing. Accuracy is key though, work out an offset from your eyes for example and you'll be in for a standard Greater Teleport rough landing.

### Tuning Network

A Resonant Anchor can be tuned to a specific pattern (number or string). Doing this allows you to create networks of anchors that can be found by using the pattern with the Resonant Anchors' Ledger. You can still use Anchor's without knowing the pattern. This is more a lookup.
