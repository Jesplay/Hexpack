# Crucible

> **Category:** Hex Wright › [[Fire & Essence (Category)|Fire & Essence]]

**Crucible**: shaped crafting

|   |   |   |
|---|---|---|

| `S` | `S` | `S` |

`I` = Iron Ingot · `A` = Amethyst Shard · `S` = Smooth Stone

Burn items in the amethyst infused Crucible to extract their [[Essence|essence]]. Unforunately not everything can have their essence extracted, it's seems some experimentation is in order.

The discoverd lab notes also has some diagrams indicated it can be fed using mundane means, like a hopper.
Hex Wrights appear to have been practical, if also not a bit eccentric. I think modern Hex Casting could easily do a better job than a simple hopper.
It's handy I can keep all my experiment notes in my journal.
