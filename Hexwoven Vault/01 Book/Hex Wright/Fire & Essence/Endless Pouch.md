# Endless Pouch

> **Category:** Hex Wright › [[Fire & Essence (Category)|Fire & Essence]]  
> **Source mod:** [[Hexwright]]

**Endless Pouch**: shaped crafting

|   |   |   |
|---|---|---|
| `S` | `L` | `S` |
| `L` | `A` | `L` |
|   | `L` |   |

`S` = String · `L` = Leather · `A` = Amethyst Shard

An Endless Pouch is what holds essence. It can hold far more than an average container. This is what's needed to store and use Essence in the Hex Wright's workstations.
