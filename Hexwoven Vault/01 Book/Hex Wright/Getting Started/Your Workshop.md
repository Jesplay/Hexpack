# Your Workshop

> **Category:** Hex Wright › [[Getting Started (Hex Wright) (Category)|Getting Started]]  
> **Source mod:** [[Hexwright]]

Starting out requires only a [[Crucible|crucible]]to start turning items into Essence. You then want an [[Essence Forge]] to forge that Essence into useful items and devices. Eventually you'll want a [[Staff Assembly Station|Staff Assembly]] station to put those [[Staff Cores|cores]]you build to good use.

### Automation

A Good Hex Workshop is an automated one.  All of the work stations can be automated with either traditional tools like hoppers and redstone, with hex, or both.
One example we've recovered from a past Hex Wrights diary speaks of using [[Warding Box|Warding Boxes]] to detect dropped items.

These items were then redirected to a hopper feeding into a [[Crucible|crucible]].
A [[Harmonic Transducer|transducer]]placed on the crucible would signal when the crucible was done and would signal an [[Harmonic Emitter|emitter]]to start a few [[Coalescer|coalescers]]producing desired items.
This was just one example, there's many different approaches one can take.
