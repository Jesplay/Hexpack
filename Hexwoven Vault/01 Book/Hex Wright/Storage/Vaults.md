# Vaults

> **Category:** Hex Wright › [[Storage (Category)|Storage]]  
> **Source mod:** [[Hexwright]]

### Vaults

*Item:* **Vault Key**

Tiny pockets of reality created using fragments of the World Crystal and reached through a portal you can open anywhere. Used by the long gone Hex Wrights to store their personal wealth and treasure.

### Forging a Key

Blank Vault Keys are made at the [[Essence Forge]].

First use forces the creation of a reality pocket.
After that, using the key opens its Vault wherever you happen to be standing. Use it again to close the door. Doors automatically shut when you move away.

### I have a lot of stuff!

The [[Qualities|quality]] of the key affects the size of the reality pocket that's created. The better the quality, the bigger the vault.
The truly skilled can create **Masterwork** vaults, which resemble a large demiplane rather than a small bubble of reality.

It's rumoured that some of the original

Hex Wrights' vaults still exist. Masterworks that were used as residences and workshops. They're now considered rare artifacts.

### The Door

A door remains open if anyone stands near either side of it, and closes on its own a few seconds after it's left unattended.

A vault's last open door will never close while someone is still inside.

A Vault cannot be opened from within a Vault.

### Sharing a Key

You can create a copy of a key by crafting a blank key with a non-blank key. The blank key is consumed and you get back the original key and a copy of it. Both keys point to the same vault. Important to note each door to the vault can only be open in one place at a time, so a door can move if someone uses their key when it's open.

### Artificial Doors

A vault's owner can give it up to two more doors.

Build a ring of Carved Bindstone 4 wide and 5 tall around a clear 2x3 opening inside the vault, then use a blank key of the vault's own quality on it and an **Masterwork** for an Artifact vault. That key now opens this door, and only this door.

An Artificial Vault Door can only be held open by one person at a time, and follows the same allow rules set on the vault, an Artificial Vault Key cannot be used to set Vault Permissions.
Break the frame and the key and door pair is gone for good, requiring a new key. Anyone who came in through it is thrown out, and its keys stop working.

### Unwanted Visitors

Don't just let anyone wander in!

You can configure who your door lets through. Set to allow only some, it becomes a wall to everyone not given access.

By default vault doors are open to anyone.

Only a real vault key can cvonfigure the vault.
