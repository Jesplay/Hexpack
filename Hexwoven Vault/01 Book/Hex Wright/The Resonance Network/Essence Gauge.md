# Essence Gauge

> **Category:** Hex Wright › [[The Resonance Network (Category)|The Resonance Network]]  
> **Source mod:** [[Hexwright]]

**Essence Gauge**: shaped crafting

|   |   |   |
|---|---|---|
| `G` | `G` | `G` |
| `A` | `R` | `A` |
| `S` | `S` | `S` |

`G` = Glass · `A` = Amethyst Shard · `R` = Redstone · `S` = Smooth Stone

Use a resonant key (or pouch) on the gauge and right-click to choose an aspect to monitor. A comparator reads one strength per 20 essence. Sneak-click to take the source back.


**Sources:** 🧩 [Hexwright on Modrinth](https://modrinth.com/mod/DXkdjl8n)
