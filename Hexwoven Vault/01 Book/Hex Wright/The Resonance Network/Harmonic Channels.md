# Harmonic Channels

> **Category:** Hex Wright › [[The Resonance Network (Category)|The Resonance Network]]  
> **Source mod:** [[Hexwright]]

### Two Kinds of Speech

There are two ways to put an [[Iotas|iota]] onto a harmonic channel. One sends to all actively listening, the other sends and saves it as state, re-sending to those who join channels.

Resonance can be got by casting [[Chronicler's Purification]] at a [[Resonance Tower]].

`resonance or null, number, any` → `—`

This is Setting State. Whoever is listening at that instant hears it. Whoever connects to

the harmonic channel later also hears it.

Each harmonic channel has its own state.

Setting that state replaces the current state.

Costs 1 Dust

### Which To Use

"A mob just died at the north gate" is an event, so broadcast it.

"The door is open" is a fact, so set it as state.

If someone arriving after a message needs to know, it must be set as state.
