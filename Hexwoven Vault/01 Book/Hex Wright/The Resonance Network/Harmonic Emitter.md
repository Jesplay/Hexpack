# Harmonic Emitter

> **Category:** Hex Wright › [[The Resonance Network (Category)|The Resonance Network]]  
> **Source mod:** [[Hexwright]]

### Harmonic Emitter

*Item:* **Harmonic Emitter**

A harmonic subscription device like the [[Resonant Rings|ring]]but instead it is placed.

Give it a harmonic channel and a hex, when that channel receives a message, it will cast its' Hex. Has a 4 block ambit.

**Harmonic Emitter** ×2: shaped crafting

|   |   |   |
|---|---|---|
|   | `A` |   |
| `S` | `C` | `S` |
| `D` | `D` | `D` |

`A` = Amethyst Shard · `S` = Sculk Sensor · `C` = Kyanite · `D` = Polished Deepslate

### Tuning

An Emitter requires a [[Resonant Key|resonant key]] to connect to the desired Network.
Connecting it alone is not enough, it also needs to be tuned using [[Emitter's Gambit]].

### One Channel Wonder

Unlike a ring that can hold up to 3 subscriptions, an Emitter can only handle one channel. You can use multiple emitters for different channels or the same channel if required.

`—` → `vector`

Returns the vector location of the emitter. Only works inside an Emitter's cast.

### Capabilities

The emitter has a limited ambit of 4 and a [[Media|media]] reserve of 500 dust. This must be filled manually by right clicking the emitter with a media source.

### Configuration

Right clicking the emitter will bring up a summary. It provides information about network, channel attunement, messages and media.
