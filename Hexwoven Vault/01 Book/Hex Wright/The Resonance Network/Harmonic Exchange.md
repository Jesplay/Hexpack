# Harmonic Exchange

> **Category:** Hex Wright › [[The Resonance Network (Category)|The Resonance Network]]  
> **Source mod:** [[Hexwright]]

### Harmonic Exchange

*Item:* **Harmonic Exchange**

A Harmonic Exchange adds 16 harmonic channels to a Resonance Network. Messages sent to the harmonic channels are forwarded to all devices subscribed.

Connect to a network using a [[Resonant Key]].

**Harmonic Exchange**: shaped crafting

`A` = Amethyst Shard · `C` = Kyanite · `S` = Sculk Sensor · `E` = Ender Pearl · `D` = Polished Deepslate

### Harmonic Channels

Each network can carry 16 harmonic channels. Certain items, like a [[Resonant Rings|ring]] or [[Harmonic Emitter|emitter]], can subscribe to these channels.

A channel can either be broadcast to or have it's state set and subscribed devices will be notified when this happens and react accordingly.

The difference between a broadcast and state is that a broadcast is short lived, only those subscribed to the channel at the time of broadcast will get the data.

Setting state will also send data to those subscribed but will also be sent when an item first subscribes. A channel only has one state.

### Range

The Exchange itself must stand within 48 blocks of its [[Resonance Tower]], and be in the same dimension.

The Exchance itself has unlimited range, and can transmit across dimensions.
