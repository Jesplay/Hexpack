# Focal Frame

> **Category:** [[Items (Category)|Items]]  
> **Source mod:** [[HexDebug]]

[[Focus|Foci]] are useful for storing **Hexes** and other [[Iotas|iotas]] in my inventory, but I sometimes find myself in need of a way to store iotas in the world. **Item Frames** are too fragile, and [[Akashic Libraries|other methods]] are inefficient and... distasteful. A cleaner solution is necessary, and I've devised one in the form of the **Focal Frame**.

A **Focal Frame** by itself is useless. An [[Focus|iota-holding item]] must first be inserted by right-clicking a placed **Frame** with the item, or by using a single **Frame** in my inventory in a manner akin to a **Bundle**. Right-clicking with an empty hand extracts the item.

As an item, I can use a filled **Focal Frame** with any [[Scribe's Reflection|patterns]] or [[Splicing Table|blocks]] that would accept the contained item. When placed in the world, I can access it using patterns like [[Chronicler's Purification]].
