# Imbuement Bed

> **Category:** [[Items (Category)|Items]]  
> **Source mod:** [[Hierophantics]]

Weaving one mind into another is a delicate process, and one that would be impossible to perform on myself without external aid.

The **Imbuement Bed** provides that aid, using the framework of an empty impetus to carefully direct incoming minds and integrate them into whatever being lays atop it.

**Imbuement Bed**: shaped crafting

|   |   |   |
|---|---|---|
|   |   |   |
| `S` | `S` | `I` |
| `P` | `P` | `P` |

`S` = Slate · `I` = Empty Impetus · `P` = any planks

Once the subject is on the bed, a new mind can be provided to either of its two blocks in the [[On The Flaying of Minds|usual manner]]. I must be careful, though: if a mind is provided while the bed is empty, it will be wasted!

### Redstone Integration

To aid in automation, the **Imbuement Bed** can be measured with a comparator to determine the status of its occupant.

A player on the bed will produce a signal strength of 15, a villager will produce a signal strength of 7, and an empty bed will produce no signal at all.
