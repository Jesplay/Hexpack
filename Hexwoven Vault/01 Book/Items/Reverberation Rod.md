# Reverberation Rod

> **Category:** [[Items (Category)|Items]]  
> **Source mod:** [[Oneironaut]]

I've discovered that I can craft a peculiar sort of casting item, using the strange shards found in ancient cities.
This item is unusual in that it casts its imbued hex twenty times per second while I concentrate on it, until it either [[Mishaps|mishaps]] or I cast Finale or Encore. This initiates a cooldown period, usually about one second.

**Reverberation Rod**: shaped crafting

|   |   |   |
|---|---|---|
|   | `E` |   |
| `O` | `C` | `O` |
|   | `E` |   |

`E` = Echo Shard · `O` = Obsidian · `C` = Charged Amethyst

The echo shards seem to bear some bizarre form of [[Media|media]], with a tendency to loop back on itself while retaining a bit of the previous cast.
