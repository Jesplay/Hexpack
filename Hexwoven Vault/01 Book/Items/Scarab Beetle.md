# Scarab Beetle

> **Category:** [[Items (Category)|Items]]  
> **Source mod:** [[Hexical]]

A **Scarab Beetle** is an adorable little amulet that is highly sensitive to **[[Media|media]]**. When activated, they can intercept patterns rejected by Nature.

Specifically when anything connected to my person casts a pattern that has no meaning to Nature, the scarab steps in and prevents the [[Mishaps|mishap]].

*Whatever. Go my scarab.*

**Scarab Beetle**: shaped crafting

|   |   |   |
|---|---|---|

`A` = Amethyst Dust · `C` = Copper Ingot · `S` = Sculk Sensor

I can instruct my scarab how to judge these "illegal" patterns and how to replace it with a different set of patterns instead. This allows me to make *new* patterns that work seamlessly for only me, even in [[Casting Items|casting devices]].

Teaching them involves [[Scribe's Gambit]] to teach a **Hex** to them. While scarabs proudly display their learned **Hex**, they resist mind-reading from [[Scribe's Reflection]]. I can reteach them at any time.

When an illegal pattern is cast, an active scarab will push the rejected pattern to the [[The Stack|stack]] rather than allowing a mishap. It will then cast its learned **Hex** and allow the remainder of the original **Hex** to continue.

The power scarabs allow is to create my own patterns that will work seamlessly in my [[Staves|Staff]] or the [[Casting Items|casting devices]] I wield.

I shall find these patterns concerning the [[Pattern Manipulation|meta-manipulation of patterns]] useful if I want to implement advanced processing. I could theoretically create entire infinite families of patterns, similar to the [[Number Literals|number literals]] and [[Bookkeeper's Gambit|Bookkeeper's Gambits]].
