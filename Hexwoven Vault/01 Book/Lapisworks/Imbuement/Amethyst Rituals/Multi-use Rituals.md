# Multi-use Rituals

> **Category:** Lapisworks › Imbuement › [[Amethyst Rituals (Category)|Amethyst Rituals]]  
> **Source mod:** [[Lapisworks]]

A **Multi-use Ritual** consists of all the parts of a **One-time Ritual** and one extra. A starter. A stable starting block to control the ritual and prevent the [[Media|media]] from burning up all the chalk in it's path. I may call it, a **Ritus** (pronounced "right-us").

**Ritus**: shaped crafting

|   |   |   |
|---|---|---|
|   | `A` |   |
| `S` | `C` | `S` |
| `A` | `G` | `A` |

`A` = any amel · `S` = Slate · `C` = Charged Amethyst · `G` = Gold Ingot

*Any ritual may pass over it as if it were chalk, and **One-time Rituals*** *do not burn it up when they do.*

If Right-Click it with some **Amel** in my hand (or in an [[Amel Storage|Amel Jar]] in my hand, or equipped on me if my hand is empty), it activates, starting up the **Multi-use Ritual** (in the direction I was facing if possible). If I Right-Click it with a readable [[Iotas|iota]] holder (such as a **[[Focus|Focus]]**) in my hand, it tunes itself (and any ritual it's executing) to the iota within. Due to the degree of control of the Ritus, it's rituals cast as me, but have no ambit around me like **One-time Rituals** do.
