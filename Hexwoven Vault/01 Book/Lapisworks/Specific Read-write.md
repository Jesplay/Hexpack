# Specific Read-write

> **Category:** [[Lapisworks (Category)|Lapisworks]]  
> **Source mod:** [[Lapisworks]]

I've found out that Nature searches for items for patterns like [[Scribe's Reflection]] by finding the first valid item in my hands from my other hand. This can be a problem when e.g. I have a [[Focus|Focus]] in both hands and wish to read one (which can happen if I use a Casting Ring or some other hands-free way to cast a hex). The next four patterns are for reading, writing, or checking any specific hand of mine (in order of importance-- so 0 for main, 1 for off-hand).
*I wonder, if I had three arms, would these support the third as well?*
