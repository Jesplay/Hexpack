# Delaying Hexes

> **Category:** Patterns › [[Spells (Category)|Spells]]  
> **Source mod:** [[Hexcassettes]]

As part of their nature, **Hexes** evaluate in their entirety in one instant. To postpone **Hexes** for later, Nature has devised quite the whimsical solution: a **Cassettes** that must be crafted and then *subsumed*. I may have up to six at any time. Each one holds a **Hex** I requested to delay until that **Hex** is ready to cast. After casting, the **Cassette** becomes free to hold other **Hexes**.

**Cassette**: shaped crafting

|   |   |   |
|---|---|---|
|   | `A` |   |
| `A` | `D` | `A` |
|   | `A` |   |

`A` = Charged Amethyst · `D` = any music discs

After plating a **Music Disc** with a hefty amount of [[Amethyst|Charged Amethyst]] to enable the *abstraction*, I can add my glorious creation to my mind's collection using a combination of magic, willpower, and a lot of chewing.

`list, number, text` → `—`

A variant that takes an additional [[Text Iota|text iota]]. Queues the **Hex** under the given label.

If there is already a **Cassette** of the provided label, the provided **Hex** replaces it and takes its slot.

Otherwise, it schedules the **Hex** to an empty slot. If there are no available slots, it incurs the Parallel Processing [[Mishaps|mishap]], terminating all of my **Cassettes**.

If [[Enqueue]] can not find a free **Cassette**, it incurs the Parallel Processing mishap, terminating all of my **Cassettes**.

The minimal time I can delay a **Hex** seems to hint that the world I live in has a disturbingly low *temporal resolution*.. best not to dwell on that.

*Ibra oniki ra. QUINIO QUINIO QUINIO QUINIO alef a ra.*

The label of a **Cassette** is a [[Text Iota|text iota]] that distinguishes it from other **Cassettes**. I will need this label if I want to cancel or query information about it.

I can view all my **Cassettes** by pressing hexcassettes.ponder_cassette.

Dying also forcibly ends all of my **Cassettes**.
