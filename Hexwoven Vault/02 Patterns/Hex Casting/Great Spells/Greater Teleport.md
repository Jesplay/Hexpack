## Description

Far more powerful than [[Blink]], this spell lets me teleport an entity to anywhere in the entire world! No matter the distance, it always seems to cost about ten [[Amethyst|Charged Amethyst]].

The provided vector is an offset, not an absolute position in the world; for example, if I use (1, 0, 0), the entity will end up precisely one block east of its original position.

Unfortunately, it seems that when teleporting myself, I'm unable to remain perfectly focused. This can cause some of my items to splatter out of my inventory on arrival.

I should also note that the target will be forcibly removed from anything inanimate they are riding ... but I've read scraps that suggest animals can come along for the ride, so to speak.

## Example

Teleports an entity by a **vector offset** (not to a position), any distance. Teleport yourself 100 blocks up: [[Mind's Reflection]] → [[Vector Rfln. +Y-Y]] → [[Numerical Reflection]] `100` → [[Multiplicative Distillation]] → **Greater Teleport**. In this pack, items in your inventory can **splat out** when you teleport (`greaterTeleportSplatsItems`).
