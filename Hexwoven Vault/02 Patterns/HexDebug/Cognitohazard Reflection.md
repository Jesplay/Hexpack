## Description

Add a **Cognitohazard** to the top of the [[The Stack|stack]].

It seems certain [[Debugging Items|debugging tools]] may pose a security risk for some [[Iris' Gambit|high-level techniques]]. To help combat this, I have created this pattern.

When a **Cognitohazard** [[Iotas|iota]] is executed normally, nothing happens. However, if one is present in a **Hex** executed by a [[Debugging Items|Debugger]], it will cause the **Hex** to terminate immediately - even before the **Cognitohazard** is actually executed.
