## Description

**Simple Impeti** are pretty gullible. Returns the pattern the **Simple Impetus** at the given location (which must be within ambit) is listening for, or null if it's not listening for any particular pattern. Free.

With my **Awakening**, I have begun seeing text where it isn't (an example being [[Enchantments]]). The ancient mage does not have put any warding hexes in their encrypted notes (unlike the **OTHERS**) so I can read them freely and without an existential crisis. These pages seem to have a lot of residual [[Media|media]] clinging to them, allowing me to read off the burnt parts.
