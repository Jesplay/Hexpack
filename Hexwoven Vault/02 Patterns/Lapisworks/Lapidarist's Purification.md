before   … │ vec  ◂ top

## Description

Returns the [[Iotas|iota]] the **Tuneable Amethyst** at the specified position (within range) is tuned to.

The ambit **Tuneable Amethyst** provides around itself is at minimum two blocks, however depositing [[Media|media]] into it can enhance that to up to sixteen. The ambit provided is the square root of the media contained within. [[Deposit Media]] and [[Withdraw Media]] work perfectly for this.
