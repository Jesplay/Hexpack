# Pattern

A drawn pattern treated as data rather than executed. Obtained by escaping (Consideration / Introspection) and executed by Hermes' Gambit and similar.

> [!example] Example
> [[Consideration]] followed by a pattern pushes that pattern instead of running it.

See also: [[Iotas]]
