# Vector

A 3D vector (x, y, z). Used for positions, directions and velocities in the world.

> [!example] Example
> `(10, 64, -3)` is a position; `(0, 1, 0)` is "up". Built with [[Vector Exaltation]], or from [[Compass' Purification]] / [[Alidade's Purification]].

See also: [[Iotas]]
